# 🤖 Machine Learning Codes

This repository contains my **Machine Learning implementations and practical experiments** using Python. It covers important concepts from data preprocessing and feature engineering to dimensionality reduction and regression.

📌 Topics Covered

 1. Feature Engineering

Implementation of techniques used to prepare and transform raw data for Machine Learning models.

**Includes:**

* Handling categorical variables
* Feature transformation
* Feature scaling
* Feature selection
* Creating meaningful features

### 2. Finding Missing Values

Techniques for identifying and analyzing missing data in datasets.

**Includes:**

* Detecting missing values using Pandas
* Counting missing values
* Finding columns containing missing data
* Understanding the impact of missing values

### 3. PCA — Principal Component Analysis

PCA is a dimensionality reduction technique used to reduce the number of features while retaining important information from the dataset.

**Covered concepts:**

* Standardization
* Covariance
* Principal components
* Explained variance
* Dimensionality reduction
* PCA visualization

### 4. LDA — Linear Discriminant Analysis

LDA is a supervised dimensionality reduction technique that finds feature combinations that best separate different classes.

**Covered concepts:**

* Class separation
* Linear discriminants
* Dimensionality reduction
* Visualization of reduced data

### 5. Polynomial Regression

Polynomial Regression is used to model **non-linear relationships** between independent and dependent variables.

**Includes:**

* Polynomial feature generation
* Different polynomial degrees
* Model training
* Prediction
* Training and testing evaluation
* Underfitting and overfitting
* Bias–Variance Trade-off
